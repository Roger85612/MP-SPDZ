# 医疗机构联合研究MPC场景 - 代码执行流程报告

## 概述

医疗场景实现了一个隐私保护的多中心医疗研究系统，三家医院可以在不泄露患者个人信息的情况下联合分析治疗数据。系统使用Shamir秘密共享协议确保患者隐私的同时获得有价值的医疗研究洞察。

## 1. 完整代码执行流程

### 入口点
**主执行脚本**: `run_medical_mpc.py`
**启动命令**: `python3 run_medical_mpc.py`

#### 患者数据结构

```python
{
```

### 阶段3: MPC协议执行 (`mpc_executor.py`)

**协议类型**: Shamir秘密共享 (3方，诚实多数)
**执行模式**: 多线程并行执行 (无SSL简化模式)

#### 协议执行流程
```
1. 环境检查: 验证可执行文件和字节码存在
2. 参与方启动: 并发启动3个shamir-party.x进程
3. 协议执行: 各方读取私有输入并参与MPC计算
4. 结果收集: 汇总成功参与方的输出结果
```

#### 命令结构
```bash
./shamir-party.x -N 3 -p {party_id} --batch-size 8192 medical_joint_analysis
```

#### 线程执行模型
```python
def _execute_shamir_no_ssl(self):
    # 创建输出队列
    output_queues = [queue.Queue() for _ in range(3)]
    threads = []
    
    # 启动所有参与方线程
    for party_id in range(3):
        thread = threading.Thread(
            target=self._run_party_process,
            args=(party_id, output_queues[party_id])
        )
        thread.start()
        time.sleep(0.5)  # 避免竞争启动
    
    # 等待完成并收集结果
    for thread in threads:
        thread.join(timeout=60)
```

## 3. 数据流架构

### 输入数据流
```
医院数据库(私有)
↓
MPCDataGenerator.generate_medical_mpc_data()
├── 心脏科: 50名患者 → Input-P0-0 (200行数据)
├── 肿瘤科: 50名患者 → Input-P1-0 (200行数据)
└── 神经科: 50名患者 → Input-P2-0 (200行数据)
↓ 
MPC协议输入层 (总计600个数据点)
```

### 计算数据流
```
私有输入读取 (各参与方)
↓
秘密共享生成 (Shamir分享)
↓
安全多方计算
├── 年龄统计 (平均值)
├── 基线健康分析 (平均值)
├── 治疗结果 (平均值、改善度)  
├── 有效率 (改善≥20分的患者百分比)

↓
结果披露阶段
```

### 输出数据流
```
MPC计算结果
↓
隐私策略评估
├── 统计聚合 (始终披露)
├── 医疗洞察 (需业务合理性)
└── 安全指标 (条件披露)

披露的医疗研究结果
```

## 4. 关键文件职责

**职责**: 安全计算实现
**数据处理**: 
- 读取: 4数据点/患者 × 50患者 × 3医院 = 600数据点
- 计算: 不泄露个体值的聚合统计
**输出格式**: `MEDICAL_DISCLOSURE`标记结果用于解析

### `mpc_data_generator.py` - 数据层
**职责**: 真实医疗数据合成
**专业化**: 医院特定患者群体特征
**质量保证**: 验证数据范围和临床合理性

### `mpc_executor.py` - 协议运行时
**职责**: MP-SPDZ协议执行管理
**线程模型**: 并发参与方执行与同步
**恢复机制**: 多种执行策略 (协调器、顺序、直接)

### `mpc_result_disclosure.py` - 隐私框架
**职责**: 隐私保护结果披露
**策略**: 医疗特定披露规则与法规合规
**技术**: 差分隐私、k-匿名、条件披露

## 5. MPC协议执行细节

### Shamir秘密共享协议
- **安全模型**: 半诚实，诚实多数 (3方中2方)
- **字段大小**: 64位精度用于医疗计算
- **批处理**: 每批8192操作提升效率

### 执行阶段
1. **输入阶段**: 各方秘密共享患者数据
2. **计算阶段**: 共享秘密上的联合统计计算
3. **披露阶段**: 仅选择性披露聚合结果

### 安全保证
- **隐私性**: 个体患者数据永不泄露
- **正确性**: 密码学保证准确结果
- **健壮性**: 容忍3方中1方恶意行为
